03 / Timeline

Systems Engineering Chronicle

Early 2021 Genesis

First Deployment

Provisioned initial server instance on G-Portal shared hosting at age 12. Rapidly outgrew resource constraints, triggering a migration to a legacy local Windows machine running a self-managed PaperMC core build for direct configuration testing and low-latency iteration cycles.

  • G-Portal
  • PaperMC
  • Windows Host
2021 – 2022 Virtualization

Hypervisor Leap

Transitioned to headless server architecture via Proxmox VE hypervisor deployment. Shifted from direct OS hosting to isolated Linux VMs with dedicated resource allocation per service, enabling clean separation of game server workloads from host-level system processes.

  • Proxmox VE
  • Linux VMs
  • Headless
2022 – 2024 Bare Metal

Enterprise Node

Decommissioned consumer hardware in favour of an enterprise-class Supermicro Xeon server node. Applied systematic JVM flag tuning across G1GC garbage collection parameters, heap allocation boundaries, and thread affinity settings to achieve measurable throughput improvements under concurrent player load.

  • Supermicro Xeon
  • JVM Tuning
  • G1GC
2024 – 2025 Co-Location

Datacenter Migration

Executed full datacenter migration to co-located infrastructure within Skylink Datacenter, Netherlands. Deployed a dedicated AMD Ryzen 7 7700X bare-metal node providing significantly improved single-thread clock speeds and reduced thermal throttling relative to the previous Xeon generation platform.

  • Skylink DC · NL
  • Ryzen 7 7700X
  • Co-Location
Present Active

Production Core Upgrade

Operating at peak capacity from NTT FRA1, Frankfurt. Running a flagship AMD Ryzen 9 X3D high-frequency bare-metal instance with 3D V-Cache architecture for maximum L3 cache density. Configuration delivers an uncompromised, continuously locked 20.0 TPS baseline across all active game worlds and concurrent sessions.

  • NTT FRA1
  • Ryzen 9 X3D
  • 20.0 TPS Locked
  • 3D V-Cache
