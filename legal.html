Privacy Policy

1. Controller

The controller responsible for data processing on this website is the operator, reachable at info@ben-ghosti.de.

2. Hosting, CDN and Status Monitoring

This website is delivered via Cloudflare as a content delivery and security service. Cloudflare processes technical connection data (including IP address, user agent and requested URL) to deliver content and defend against attacks. Cloudflare acts as a processor. Cloudflare may process data outside the EU/EEA; it provides the necessary safeguards under Article 46 GDPR.

The monitoring embedded on the Status page runs on the controller's own subdomain status.ben-ghosti.de. The same privacy principles apply; technically necessary cookies and server log files may be generated. The data remains in the controller's own infrastructure.

3. Server Log Files

When this website is accessed, the web server (Nginx) automatically stores technical access data in server log files. The legal basis is Article 6(1)(f) GDPR (legitimate interest in maintaining system security, stability and defending against cyberattacks).

The following data is collected:

  • IP address of the requesting device (anonymised or truncated depending on server configuration)
  • Date and time of access
  • Requested URL, HTTP method and protocol version
  • HTTP status code and amount of data transferred
  • User agent (browser type and operating system)
  • Referrer URL (previously visited page), if transmitted by the browser

The log files remain on the controller's own server infrastructure, are not merged with other data sources and are deleted after 30 days, unless a specific security incident requires longer retention.

4. Cookies and Local Storage

This website does not use cookies for analytics, marketing or tracking purposes. No advertising or tracking IDs are used.

Cloudflare may set technically necessary cookies as a security service (e.g., cf_clearance or __cf_bm). These serve exclusively security and abuse prevention.

The Benpixel subpage stores the last known season and the rules consent in the browser's local storage (localStorage). This storage is necessary for functionality and contains no advertising or tracking IDs.

Non-essential cookies are not set without consent. For this reason, no cookie consent banner is used.

5. Cloudflare Web Analytics

Cloudflare Web Analytics is used for aggregate traffic measurement. The measurement is cookieless and does not create cross-site user profiles. Aggregate data is collected on page views, referrers, approximate region, device and browser category, and performance.

Cloudflare processes the necessary technical connection data as a processor. The legal basis is Article 6(1)(f) GDPR (legitimate interest in privacy-friendly traffic measurement and technical optimisation). According to the provider, the data is not merged with other data sources. No cookie consent banner is required for cookieless measurement.

6. Benpixel: Status APIs and Discord

The Benpixel subpage calls public Minecraft status APIs. The server address is transmitted to the respective API provider; the provider may process the IP address of the requesting device. External links to Discord lead to a service with its own privacy policy.

A whitelist form is currently not active. If it is activated in the future, the required data and retention periods will be described separately before use.

7. Contact by Email

If you contact us by email, the information you provide (e.g., name, email address and message content) will be processed solely to handle and respond to your enquiry. The legal basis is Article 6(1)(f) GDPR (legitimate interest in handling enquiries).

8. Your Rights

You have the right to information, rectification, erasure, restriction of processing, data portability and objection with regard to the processing of your personal data. You also have the right to lodge a complaint with a competent data protection supervisory authority.
